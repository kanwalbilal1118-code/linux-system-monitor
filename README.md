# Linux System Monitor & Automation Tool

## Description

This project is a Python-based Linux system monitoring and automation tool. It analyzes log files to detect and classify errors and provides useful system information such as CPU usage and available storage.

## Technologies

- Python
- Linux
- Bash
- CLI
- WSL
- Ubuntu
- Git & GitHub

## Purpose

The purpose of this project is to help users quickly identify system errors and monitor important system resources. It processes log files, detects specific types of errors, and provides system information such as CPU usage and available storage, helping users save time when troubleshooting.
